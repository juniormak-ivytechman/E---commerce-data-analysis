# E-Commerce Data Analysis Project

## Overview

This project is an end-to-end SQL data analytics pipeline designed to analyze e-commerce operations. It focuses on customer behavior, sales performance, product trends, seller efficiency, and delivery performance.

The project simulates a real-world analytics workflow using structured SQL layers and business KPIs.

---

## Project Structure

### 1. Data Model Layer

- Raw tables (customers, orders, products, sellers)

- Fact table (fact_orders)

- Aggregated views for business metrics

### 2. Analysis Layer

The analysis layer contains SQL scripts that generate business insights:

- Monthly revenue trends

- Product performance ranking

- Payment method analysis

- Customer segmentation

- Delivery performance and delays

- Seller performance and efficiency

---

## Key Business Insights

- Revenue trends over time

- Top performing products

- Most profitable payment methods

- Repeat vs one-time customers

- Delivery efficiency and delays

- Seller performance comparison

---

## Tools Used

- MySQL

- SQL (data modeling + analysis)

- Power BI (visualization layer)
